The build

60–70%less manual work per migration

SMS

Multi-platform BI migration accelerator, built in-house

Migrating a reporting estate by hand is slow, repetitive and easy to get wrong. SMS reads the source workbooks directly and generates the Power BI equivalent, so the team spends its time on the logic that genuinely needs a person looking at it.

  • Parses Tableau .twbx, Cognos and QlikSense artefacts and generates Power BI PBIP semantic models programmatically.
  • Extracts data sources, measures, calculated columns and relationships, emitting them as TMDL instead of hand-authored models.
  • Compresses conversion cycles that used to run for weeks down to days, without adding headcount to the delivery team.
  • Now a reusable CoE asset across client engagements, which keeps quality consistent from one migration to the next.

Python, XML and JSON parsing, Tableau TWBX, Cognos, QlikSense, Power BI PBIP, TMDL, DAX
